# La IA por dentro

Landing del ebook *La IA por dentro*. Sitio estático (HTML, CSS y JS) publicado con GitHub Pages.

- `index.html`: la página
- `css/styles.css`: estilos
- `js/main.js`: animaciones con el scroll (GSAP + ScrollTrigger)
- `vendor/`: GSAP 3.12.5 servido desde el mismo sitio
- `img/`: tapa y páginas de muestra del libro

El PDF del libro **no** va en este repo: se entrega desde la plataforma de venta.
